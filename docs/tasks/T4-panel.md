## 背景

插件"幕后"是 TauriTavern（SillyTavern 的 Tauri 重写版，兼容 ST 第三方扩展）的扩展：每轮 AI 回复后，在后台用独立模型推演镜头外的人物和暗线，下一轮只给正文模型注入一小段"幕后备注"；用户也可以让它给出剧情方案、采纳后作为引导注入。核心逻辑都已完成并通过测试，现在缺界面。

## 要做的事

### 1. 主面板 `mountPanel(api)`

- **入口**：在宿主的扩展菜单（魔杖菜单 `#extensionsMenu`）加一项"幕后"，点击开关面板。
- **形态**：桌面端为右侧抽屉（宽约 380px），手机端为全屏底部抽屉。TauriTavern 有手机版，**手机端必须可用**（触控目标 ≥ 44px，不出现横向滚动）。
- **顶部状态条**：推演中 / 已是最新 / 推演落后一轮 / 上次失败（附原因），右侧"立即推演"按钮。
- **四个标签页**：
  1. **人物**：每人一张卡片：名字、生死、是否在场、位置、当前行动、长期行动、认知（≤5 条）。操作：钉住 / 取消钉住、移除、编辑字段。
  2. **暗线**：每条一张卡片：标题、阶段、主角知情程度、引信、期限。用户采纳的线有明显标记。操作：开始引导（选强度）、调整强度、完成、放弃、编辑、删除。
  3. **纸条**：显示 `api.previewInjection()`，即下一轮会注入正文的原文，分"暗流"和"引导"两块；没有内容时说明"本轮不注入"。
  4. **规划**：一个输入框（可空）+"生成方案"按钮 → 显示最多 3 张方案卡（标题、目标、起始迹象、为什么贴合），每张可选强度后"采纳"。生成中有加载状态，失败显示原因。同一时间只能有一条引导，采纳新方案前若已有引导要提示会替换。
- 状态通过 `api.onStatus`、`api.onStateChanged` 自动刷新。
- 所有修改走 `api.editState(mutate)` 等接口；`mutate` 必须返回新对象，不要修改 `api.getState()` 返回的对象。编辑相关的纯函数（钉住、移除人物、更新字段、删除线等）放在 `src/ui/state-edits.js`，并写测试。

### 2. 设置抽屉 `mountSettings(api)`

在扩展设置区（`#extensions_settings2`）加一个标准 `inline-drawer`，包含 `Settings` 的全部字段（见 INTERFACES 3.8），连接用下拉框（`api.settings.listProfiles()`）。没选连接时要醒目提示"需要先选择推演用的连接"。

### 3. 楼层角标（第二优先级，前两项完成后再做）

在每条 AI 消息上显示一个小标记（`api.getFloorInfo(floor)`）：推演成功 / 失败 / 用户编辑过。点击打开面板。宿主消息 DOM 是 `#chat .mes[mesid="N"]`，需要在消息渲染和切换聊天后重新挂载。

## 视觉风格：Claude 网页版的极简风格

- **整体**：大量留白，信息层级靠字号和字重而不是边框和色块；圆角柔和（8–12px）；阴影极轻或不用；没有渐变和装饰性图标。
- **配色**（做成 CSS 变量，前缀 `--bs-`，所有颜色只从变量取）：
  - 浅色：背景暖米白（约 `#FAF9F5`），卡片略深一档（约 `#F0EEE6`），正文近黑（约 `#141413`），次要文字暖灰（约 `#73726C`），分隔线很淡（约 `#E8E6DC`），强调色赤陶橙（约 `#D97757`，只用于主按钮、选中态、引导标记）。
  - 深色：背景约 `#262624`，卡片约 `#30302E`，正文约 `#FAF9F5`，次要文字约 `#A6A39A`，分隔线约 `#3E3E38`，强调色同上。
  - 跟随宿主的明暗：检测宿主主题背景亮度，或用 `prefers-color-scheme` 兜底。
- **字体**：标题用衬线体（`ui-serif, Georgia, "Songti SC", serif`），正文用系统无衬线体；正文 14–15px，行高 1.6。
- **控件**：主按钮实心强调色；次要按钮透明底 + 细边；标签页用下划线指示，不用色块。
- 这是"风格参考"，**不要使用 Claude / Anthropic 的名字、标志或品牌字样**。
- 所有样式限定在 `#backstage-panel`、`#backstage_settings_v2` 等自己的根选择器下，**不能影响宿主和其他扩展的样式**。

## 开发与验证

- 你没法直接运行 TauriTavern。请在 `dev/panel-preview.html` 做一个预览页：用模拟的 `api`（数据取自 `tests/fixtures/states/*.json`，可切换样本）挂载面板，然后用内置浏览器打开检查。
  - 必须检查：浅色、深色、桌面宽度、手机宽度（375px）四种组合；四个标签页；加载、失败、空状态。
  - 预览页可以用一个简单的本地静态服务器打开（例如 `python3 -m http.server`，跑在 `dev/` 以外的端口冲突时换端口，用完关掉）。
- 纯函数测试：`tests/ui/*.test.mjs`，写法 `import { test, assert } from '../harness.js'`，运行 `sh tests/run.sh tests/ui`。用 macOS 自带的 JavaScriptCore，不需要 Node，**不要安装任何东西**。
- 代码规范见 INTERFACES 第 1 节：原生 ES 模块、无依赖、无构建、4 空格缩进、用户可见文字中文。
